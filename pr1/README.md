***Звіт з виконання практичної роботи №1***

Розробка вбудованого ПЗ для мікроконтролера STM32 (CMSIS / Bare-Metal)

***1. Мета роботи***

Опанувати низькорівневе програмування мікроконтролера STM32F103C8 (Blue Pill) на рівні регістрів з використанням бібліотеки CMSIS.
Реалізувати енергоефективну подієво-орієнтовану систему з обробкою аналогового сигналу від потенціометра, апаратним перериванням від тактової кнопки,
світлодіодною індикацією та передачею даних через послідовний інтерфейс UART.

***2. Апаратна конфігурація та підключення***
Симуляція схеми виконана в середовищі Wokwi для плати STM32 Blue Pill.

**Підключення периферії:**

A0 налаштований як аналоговий вхід (Analog Input, CNF=00, MODE=00). 
До нього підключено повзунок потенціометра, який формує сигнал для входу АЦП (ADC1_IN0).

A1 налаштований як цифровий вхід із внутрішньою підтяжкою до живлення 3.3V (Input with Pull-Up, CNF=10, MODE=00).
До нього підключена кнопка, що замикає контакт на землю (GND) та генерує зовнішнє переривання EXTI1.

A5 налаштований як цифровий вихід двотактного типу з обмеженням швидкості 2 МГц (Output Push-Pull, CNF=00, MODE=10).
До виводу через обмежувальний резистор 330 Ом підключено світлодіод.

A9 налаштований в режимі альтернативної функції (Alternate Function Push-Pull 2MHz, CNF=10, MODE=10) 
і виконує роль передавача TX модуля USART1 для виводу повідомлень у термінал.

***3. Опис алгоритму та архітектури програми***

Програма реалізована за подієво-орієнтованою моделлю зі скінченним автоматом станів.

Система підтримує два режими роботи:

Автоматичний режим (automate): стан світлодіода залежить від поточної напруги на потенціометрі.

Ручний режим (manual): світлодіод увімкнений постійно, ігноруючи значення датчика.

У автоматичному режимі система розрізняє три стани:

***chill*** (нормальний стан, значення від 0% до 44%): світлодіод повністю вимкнений.
***warning*** (стан уваги, значення від 45% до 89%): світлодіод блимає повільно з періодом 1000 мс.
***stress*** (тривожний стан, значення від 90% до 100%): світлодіод швидко блимає з періодом 250 мс.

***Особливості низькорівневої реалізації:***

Тактування периферійних блоків вмикається через регістр RCC->APB2ENR для порту GPIOA, модуля альтернативних функцій AFIO, модуля АЦП ADC1 та порту зв'язку USART1.

Системний таймер SysTick налаштований функцією SysTick_Config(8000) 
на генерацію переривань кожну 1 мілісекунду при частоті ядра 8 МГц. 
Він веде лік системного часу (system_millis), керує інтервалами блимання світлодіода та кожні 250 мс виставляє прапорець wake_up для запуску вимірювання АЦП у головному циклі.

Переривання кнопки EXTI1 налаштовано через регістри AFIO->EXTICR, EXTI->IMR, EXTI->FTSR на спрацьовування за спадаючим фронтом (натискання). 
В обробнику переривання EXTI1_IRQHandler реалізовано програмне придушення брязкоту контактів (debounce) без затримки процесора, 
що перемикає режим між automate та manual.

Зчитування потенціометра здійснюється модулем ADC1 у 12-бітному режимі. 
Значення зчитується з регістра даних ADC1->DR після підняття прапорця завершення перетворення EOC у регістрі статусу SR, після чого масштабується у відсотки від 0 до 100.

Керування світлодіодом виконується атомарно через регістр GPIOA->BSRR (біти BS5 для увімкнення та BR5 для вимкнення),
що унеможливлює помилки при одночасному доступі.

Модуль USART1 налаштовано на швидкість 115200 бод шляхом запису коефіцієнта ділення у регістр BRR. 
Вивід тексту та чисел реалізовано через побайтовий запис у регістр даних USART1->DR із контролем прапорця TXE.

Для енергозбереження в головному циклі застосовано інструкцію wfi (Wait For Interrupt). 
Ядро процесора зупиняється і спить між подіями, прокидаючись лише за апаратними сигналами від SysTick або кнопки.

***4. Висновки***
У ході виконання роботи було опановано методи роботи з мікроконтролером STM32F103 на рівні регістрів за стандартом CMSIS. 
Було успішно реалізовано систему без використання блокуючих затримок,
із застосуванням апаратних переривань, неблокуючого придушення брязкоту,
атомарного керування виводами через BSRR та переходом ядра в режим низького енергоспоживання (WFI). 
Створена прошивка успішно протестована у симуляторі Wokwi.
