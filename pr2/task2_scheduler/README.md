# Завдання 2: Планувальник часових задач (Варіант 7)

## Мета завдання
Реалізувати кооперативний неблокувальний планувальник для 4 незалежних задач з індивідуальними періодами та мітками часу. Довести експериментально незалежність задач та відсутність взаємного блокування.

## Характеристики задач (Варіант 7)
1. **Heartbeat (900 мс):** інверсія стану вбудованого світлодіода `PC13` незалежно від режиму.
2. **Оновлення RGB (30 мс):** формування кроку зміни кольору та оновлення PWM-виходів.
3. **Обробка кнопки:** опитування з фільтрацією брязкоту контактів (debounce 50 мс).
4. **Телеметрія (1000 мс):** вивід у Serial Monitor поточних параметрів, кольору та заповнення PWM (duty cycle).

## Теоретичне обґрунтування стійкості до переповнення
Вираз:
```cpp
if (current_time - last_run >= interval)
```
працює коректно навіть у момент переповнення беззнакового 32-бітного лічильника `millis()` (при переході через $2^{32} - 1 \approx 4\,294\,967\,295$). Завдяки властивостям арифметики за модулем $2^{32}$ у додатковому коді, операція `(current_time - last_run)` завжди повертає коректну різницю в часі $\Delta t$, якщо сам інтервал менший за $2^{31}$ мс.

## Очікувані результати за 10 секунд симуляції
Після 10000 мс програма автоматично виводить статистику:
* **Heartbeat:** 11 запусків ($\approx 10000 / 900$).
* **RGB Update:** $\approx 333$ запуски ($10000 / 30$).
* **Telemetry:** 10 запусків ($10000 / 1000$).
* **Кількість проходів loop():** понад 100 000 ітерацій, що доводить відсутність будь-яких затримок.
