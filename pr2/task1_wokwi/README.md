# Завдання 1: Створення та верифікація схеми Wokwi (Варіант 7)

## Мета завдання
Створити принципову схему симуляції у Wokwi для мікроконтролера STM32 Blue Pill (`STM32F103C8`), підключити RGB-світлодіод зі спільним катодом, 3 струмообмежувальні резистори 330 Ом, тактову кнопку, Logic Analyzer та налаштувати зв'язок із Serial Monitor.

## Таблиця з'єднань
| Елемент | Вивід Blue Pill | Призначення | Режим / Примітка |
| :--- | :--- | :--- | :--- |
| **RGB LED Червоний (R)** | `PA6` | Керування червоним каналом | TIM3_CH1, через резистор 330 Ом |
| **RGB LED Зелений (G)** | `PA7` | Керування зеленим каналом | TIM3_CH2, через резистор 330 Ом |
| **RGB LED Синій (B)** | `PB0` | Керування синім каналом | TIM3_CH3, через резистор 330 Ом |
| **RGB LED Спільний (COM)**| `GND` | Спільний катод | Підключений до GND.2 |
| **Кнопка** | `PB12` | Вхід керування | `INPUT_PULLUP`, замикання на GND |
| **Вбудований LED** | `PC13` | Індикатор Heartbeat | Активний низьким рівнем (LOW = горить) |
| **Logic Analyzer D0** | `PA6` | Канал червоного кольору | Запис PWM сигналу |
| **Logic Analyzer D1** | `PA7` | Канал зеленого кольору | Запис PWM сигналу |
| **Logic Analyzer D2** | `PB0` | Канал синього кольору | Запис PWM сигналу |
| **Logic Analyzer D3** | `PC13` | Канал Heartbeat | Запис перемикання 900 мс |
| **Serial Monitor** | `PA9/PA10`| UART TX / RX | Швидкість 115200 бод |

## Запуск та верифікація
1. Відкрийте файл `diagram.json` у Wokwi (або в середовищі VSCode з плагіном Wokwi).
2. Запустіть симуляцію.
3. Спостерігайте почергове увімкнення червоного, зеленого та синього кольорів світлодіода.
4. Вбудований світлодіод PC13 перемикається раз на 900 мс (відповідно до Варіанта 7).
5. При натисканні клавіші `1` (або кліку на кнопку) у Serial Monitor надсилається підтвердження: `Button PB12 PRESSED`.
