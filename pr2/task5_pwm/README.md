# Завдання 5: Формування кольору через PWM (Варіант 7)

## Мета завдання
Реалізувати керування триканальним апаратним PWM (таймер `TIM3` на пінах `PA6`, `PA7`, `PB0`) для плавного формування кольорів відповідно до індивідуального Варіанта 7.

## Параметри Варіанта 7
* **Кольори AUTO:** `синій` $(0, 0, 255) \to$ `пурпурний` $(255, 0, 255) \to$ `білий` $(255, 255, 255) \to$ `синій`.
* **Тривалість переходу:** $1900$ мс (задається окремо від періоду PWM).
* **Крок оновлення PWM:** $30$ мс.
* **Пульсація ALARM (червоний канал):** $25\dots 255$ з періодом 1000 мс (G=0, B=0).
* **Режим MANUAL:** 5 фіксованих станів (`RED`, `GREEN`, `BLUE`, `YELLOW`, `OFF`).

## Формула лінійної інтерполяції (LERP)
Для кожного каналу $C \in \{R, G, B\}$ у будь-який момент часу $t \in [0, T_{fade}]$:
$$C(t) = C_{start} + \frac{(C_{target} - C_{start}) \cdot t}{T_{fade}}$$

## Захист від стрибка кольору
Під час зміни режиму (наприклад, повернення з `ALARM` або перехід з `MANUAL` в `AUTO`) початковою точкою $C_{start}$ призначається **поточне дійсне значення PWM** світлодіода. Плавний рух починається саме з цього кольору без різкого стрибка яскравості.
