# Завдання 3: Обробка кнопки через переривання (Варіант 7)

## Мета завдання
Налаштувати зовнішнє переривання EXTI на виводі `PB12` із внутрішнім підтягуванням (`INPUT_PULLUP`). Обробник переривання `button_exti_isr()` має виключно встановлювати volatile-прапорець події, а вся фільтрація брязкоту контактів (debounce 50 мс) та класифікація жестів виконуються в основному циклі `loop()`.

## Класифікація жестів
1. **Коротке натискання (Short Press):**
   * Тривалість натискання: $50\dots 1500$ мс без повторного кліку протягом 350 мс.
   * Дія: перехід `STOP -> AUTO`, `AUTO -> MANUAL` або вибір наступного кольору в `MANUAL`.
2. **Подвійне натискання (Double Click):**
   * Дві послідовні короткі дії з паузою менше 350 мс між ними.
   * Дія: перехід `MANUAL -> STOP`.
3. **Довге утримання (Long Press):**
   * Утримання кнопки натиснутою понад 1500 мс.
   * Дія: перехід у режим `ALARM` (із запам'ятовуванням попереднього) або повернення з `ALARM` у попередній режим.

## Захист від брязкоту (Debounce)
Використовується часовий поріг 50 мс. Швидкі сплески та шум брязкоту контактів (< 50 мс) автоматично відсікаються програмним автоматом, що гарантує відсутність хибних переходів.
