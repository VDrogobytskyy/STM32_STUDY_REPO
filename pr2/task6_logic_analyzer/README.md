# Завдання 6: Вимірювання Logic Analyzer (Варіант 7)

## Мета завдання
Підключити канали віртуального логічного аналізатора Wokwi до відповідних виводів STM32 Blue Pill, записати щонайменше 10 секунд роботи сигналів, визначити період, частоту, тривалість імпульсу HIGH та duty cycle, а також порівняти їх із розрахунковими значеннями.

## Призначення каналів аналізатора
* **D0:** `PA6` (Червоний канал, PWM)
* **D1:** `PA7` (Зелений канал, PWM)
* **D2:** `PB0` (Синій канал, PWM)
* **D3:** `PC13` (Heartbeat, інтервал 900 мс)

## Калібрувальна таблиця вимірювань PWM
Для стандартної частоти PWM у ядрі Arduino STM32 ($f = 1000\text{ Гц}$, період $T = 1000\text{ мкс}$):

| PWM Значення | Розрахований Duty Cycle | Тривалість HIGH ($t_{high}$) | Період ($T$) | Частота ($f$) |
| :---: | :---: | :---: | :---: | :---: |
| **64** | $\frac{64}{255} \times 100\% \approx \mathbf{25.10\%}$ | $251.0\text{ мкс}$ | $1000\text{ мкс}$ | $1000\text{ Гц}$ |
| **128** | $\frac{128}{255} \times 100\% \approx \mathbf{50.20\%}$ | $502.0\text{ мкс}$ | $1000\text{ мкс}$ | $1000\text{ Гц}$ |
| **191** | $\frac{191}{255} \times 100\% \approx \mathbf{74.90\%}$ | $749.0\text{ мкс}$ | $1000\text{ мкс}$ | $1000\text{ Гц}$ |

### Висновок для звіту:
Частота PWM залишається абсолютно стабільною ($1\text{ кГц}$), а зміна яскравості досягається пропорційною зміною тривалості високого рівня $t_{high}$ у межах кожного періоду.

## Перевірка каналу Heartbeat (D3 / PC13)
* **Виміряний напівперіод (стан LOW або HIGH):** $900\text{ мс}$ (відповідно до Варіанта 7).
* **Повний період сигналу ($T_{hb}$):** $1800\text{ мс}$ ($1.8\text{ с}$).
* **Частота блимання:** $f = \frac{1}{1.8} \approx 0.555\text{ Гц}$.

## Робота з VCD-файлом
1. Запустіть симуляцію у Wokwi на 15–20 секунд.
2. Зупиніть симуляцію. У корені проєкту з'явиться файл `wokwi.vcd`.
3. Для автоматичного розрахунку запустіть скрипт:
   ```bash
   python3 analyze_vcd.py wokwi.vcd
   ```
4. Для перегляду часових діаграм відкрийте файл у програмі **PulseView** (sigrok) або **GTKWave**.
